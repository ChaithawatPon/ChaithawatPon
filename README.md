# Agent Skills and Automation Portfolio

Open-source, privacy-reviewed workflows for practical agent-assisted work.

## Main Catalog

Install the public skill set from one repository:

```bash
npx skills add ChaithawatPon/skills
```

Source: [ChaithawatPon/skills](https://github.com/ChaithawatPon/skills)

## What Is Inside

- Selling workflows for Marketplace and seller-center work.
- University workflows for assignment scanning, explanations, and review-ready drafts.
- Daily workflows for Obsidian notes and session handoffs.
- Career workflows for professional profiles, public content, and opportunity tracking.
- Media workflows for reviewed video-edit plans, previews, captions, and exports.

## Quality Contract

Every listed skill must provide:

- a valid `SKILL.md` and complete installation instructions;
- declared requirements, configuration, usage, and troubleshooting guidance;
- synthetic examples and fixtures instead of personal or customer data;
- deterministic validation and meaningful tests where runtime behavior exists;
- explicit privacy and approval boundaries;
- an independent license and release history.

## Privacy Boundary

The catalog links only to public-safe source. It does not publish browser state,
credentials, local paths, personal profiles, private messages, screenshots,
customer or employer content, or runtime output.

Before a release, each package is checked for structure, dependencies, tests,
secrets, personal data in Latin and Thai text, external symlinks, and full Git
history.
